## Observation, causal model and controller

At tick t observe only preceding transition's B GABAA conductances, the eight source spike bits (from previous integration), tick and own internal history. For the transition t to t+1 the simulator uses the source spikes at t, and
g_B(t+1)=d[g_B(t)+0.5(c0*n0(t)+c1*n1(t))], d=exp(-0.1/6).
The current injected at t influences future spikes; it is NOT an instantaneous conductance actuator. Reconstruct residual g_B(t+1)-d*g_B(t) independently for each receiver. Exact model tolerance 1e-9 nS, only numerical slack; no stochastic sensor model claimed. Candidate predicted residuals follow from the actual observed source spikes and known candidate masks, not the hidden mode. A nominal inconsistency triggers detection and resets to all four candidates; intersect thereafter. True-mode elimination, empty candidate set and false no-change detection are model/instrument failures. Lack of sufficient excitation leaves a set-valued result, never guessed singleton. One active spike in each group at separate ticks is sufficient to discriminate all four masks.
