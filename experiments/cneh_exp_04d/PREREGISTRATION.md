# CNEH-EXP-04D — prospective repeated structural change under partial observation

**Authority:** internal engineered neural mechanism pilot. Reuses the actual pinned EXP04B BN-Syn plant and the EXP04C set-valued residual filter. Does not modify the frozen parents or their outcomes. Execution on this stacked branch is integration testing; scientific interpretation requires the parent PRs to close. This protocol precedes the new implementation and new cohort outcomes.

## Plant, interventions and cohort

Reuse 32 AdEx neurons, 24 E/8 I, B=0..15, two controllable inhibitory groups 24..27 and 28..31, 0.5 nS edges, reference backend, dt=0.1 ms, common applied gain 1, B injected current 300 pA, other E input zero, at most one source group injected with 500 pA per transition. All other connections zero, residual conductances retained at every switch. Same pinned simulator commit and authenticated dependency scope as EXP04B. Four hidden modes M0=(1,0), M1=(0,1), M2=(1,1), M3=(0,0).

Horizon 3200 transitions. Eight new public OOD seeds 87001..87008, cyclically assigned successive distinct mode sequences (1,3,2), (2,3,0), (3,1,2), (3,2,0), after nominal M0. Hidden transition ticks are independently drawn uniformly from [650,750], [1450,1550], [2250,2350] using Python Random(seed). Four additional no-change fixtures 87101..87104. All have the same nominal initial regime. No outcomes used to pick seeds, switches or controllers. All OOD worlds disconnect and reconnect at least once. Mode switches before the respective state transition, never before its observation. No controller receives the schedule, current mode, topology, seed, latent true conductance, true spike counts or future tape.

## Observation and candidate renewal

At state observation t, observe all 16 B conductances plus independent uniform errors in [-0.01,0.01] nS, **without clipping**, and source spike bits independently erased (not flipped) with probability 0.25. Additional complete source-bit blackout at ticks 1000..1099 and 2000..2099, independent of the hidden switches. Sensor noise/erasures generated by a separate Random(seed + 1000000) stream; identical across all paired arms. Plant RNG remains independent. This is controlled simulated corruption of real BN-Syn observations, not qualification of a physical sensor.

Use EXP04C support over all four modes at every completed transition. A shared integer arrival count must explain every observed residual. The instantaneous support contains the true transition mode under the model/error assumptions. An empty instantaneous support is instrument failure. For repeated changes, intersect the previous epoch's conditional candidates with instantaneous support. If intersection is empty, record a contradiction, reset to instantaneous support and start a new evidence epoch. Independently renew the evidence epoch on each observation tick divisible by 400; record this scheduled renewal separately from contradictions. Renew before intersection, retaining instantaneous evidence. Initial candidate is M0. A singleton of accumulated epoch evidence is conditional on persistence within that epoch, **not** guaranteed to describe the current hidden mode after an undetected switch. Between a switch and new informative data, old evidence can be stale. Score stale and ambiguous ticks explicitly; do not call them oracle leakage, false exclusion of the instantaneous filter, or successful identification. A correct epoch singleton must persist at least 20 consecutive observations to count as recovered identification. A scheduled renewal by itself is not a detection. No forced collapse of ambiguous sets.

## Policies and actuation

Five paired arms: ACTIVE_REID, EXACT_EMULATOR (identical active implementation), PERIODIC_REID, STATIC_NOMINAL, privileged diagnostic ORACLE. All use EXP04B's sentinel schedule (first 100 ticks of each 200-tick interval, alternating group). ACTIVE while ambiguous chooses EXP04B's pair-count distinguishing group, with ties by index; PERIODIC while ambiguous uses sentinels only; otherwise both use a singleton's predicted connected group and track against noisy mean B GABA (goal 0.5 nS), using the lexicographically first connected source if below goal. If conditional singleton is disconnected, do not track; sentinels may still test connectivity. STATIC always follows nominal M0 with the same sentinel schedule. ORACLE uses true mode and noisy GABA but is explicitly diagnostic, not a resource-matched upper bound. Actions always bounded; neither ambiguity nor disconnected prediction allows tracking. Applied gain fixed before each step. Exact emulator parity required; no claim of beating it. Record all action counts and source-current proxies, not physical energy.

For reachable regimes measure first 10 consecutive observations with correct singleton and actual mean conductance within [0.4,0.6] nS, latency from tau, mean absolute tracking error and in-band fraction; measure conductance error/fraction also for static/oracle but do not credit those arms with identification. For disconnected mode, identification and abstention are scored separately, never positive-goal recovery. A segment with no sustained identification or recovery remains UNRESOLVED.
