## Correct mathematical contract

Let W be a finite nonempty set of compatible worlds, A a finite nonempty action set, L(w,a) an exact rational loss matrix, and epsilon >= 0. Define r(w,a)=L(w,a)-min_b L(w,b), R_W(a)=max_{w in W} r(w,a), C_e(w)={a:r(w,a)<=epsilon}. Distinguish:
- minimax LOSS = argmin_a max_w L(w,a);
- minimax REGRET = argmin_a R_W(a);
- uniform epsilon-sufficiency = intersection_{w in W} C_e(w) nonempty.
A unique minimax-regret minimizer does NOT imply uniform optimality or tolerable regret. A uniform epsilon-sufficient action need not be unique. A gap between minimax scores is not a regret allowance. Abstain if the intersection is empty; an empty W is inconsistency, not vacuous authorization. In an outer cover W+ containing actual feasible worlds, a uniform action certificate is sound conditional on the cover and loss contract, but feasibility must be separately witnessed; lack of an action on W+ does not prove impossibility on W. Actions here are abstract labels, not physical commands.

Theorem 1: the intersection equals {a:R_W(a)<=epsilon}. Proof: expand the universal quantifier in C_e and apply the finite maximum. At epsilon=0, this is common pointwise optimality, more stringent than minimax optimality. For W' subset W, nonempty, the intersection can only enlarge and min_a R_W'(a) cannot increase; this holds for a fixed model, not revising the hypothesis class, and does not imply realized Bayesian entropy decreases. State-independent shifts L'(w,a)=L(w,a)+c(w) preserve r and all decision regions, but can change minimax LOSS.

Theorem 2 (finite obstruction): if no epsilon-sufficient action exists, choose for every a one world violating its threshold. Their union is an obstruction of size <= |A|, and has empty intersection. Conversely any empty-intersection subset blocks its supersets. Pairwise tests alone are insufficient for >=3 actions with overlapping acceptable regions: {a,b}, {b,c}, {a,c} have pairwise overlap and empty triple intersection. Treat these as hyperedges, not only contradictory pairs. This is a finite decision-region fact, not a novelty claim.

## Exact acquisition model

A finite catalogue T of deterministic tests t:W->finite outcomes, strictly positive rational costs c(t), no state change, no noise, no repeated acquisition. Each branch retains exactly W_y={w:t(w)=y}; reject impossible observations. Terminal criterion is nonempty uniform epsilon-sufficient action set; full-ID comparator instead requires |W|=1. Infinite cost means impossible under this catalogue, not timeout. Optimal worst-case cost V(W,S) is zero at a terminal set; otherwise min over unused splitting tests t in S of c(t)+max_{y:W_y nonempty} V(W_y,S\{t}); if no finite plan exists, V=infinity. Proof by induction on |S| using the first test of an optimal deterministic tree; constant tests cannot improve the worst-case cost. A budgeted controller may abstain, but abstention never counts as success for this cost-to-success oracle. Bounded exhaustive oracle, maximum 8 worlds, 4 actions, 8 tests. Complexity upper bound O(2^|W|*2^|T|*|T|*|W|*|A|) under memoization, ignoring rational bit complexity. No claim about arbitrary stochastic/adversarial acquisition, dynamics, or real-time execution.

Theorem 3 (static obstruction cover): a static test subset succeeds on all worlds iff each inclusion-minimal obstruction contains two worlds differentiated by at least one chosen test. For the forward direction, otherwise that obstruction survives in one fiber. For the reverse, any failed fiber contains a minimal obstruction because W is finite. Thus minimum-cost static acquisition in this contract is weighted set cover over obstruction hyperedges. NP-hardness even with two actions and epsilon=0 follows from Set Cover: take a unique base world w0 requiring a, each element world wi requiring b, and a binary test for each set that signals membership of element worlds and returns zero at w0. The conflicting pairs {w0,wi} are precisely the obligations. Any successful selection covers all elements, and vice versa. This reduction is for static exact acquisition, not a universal complexity result.

Adaptive worst-case optimum <= static optimum <= full-identification static optimum when finite; adaptation may strictly help. An immediate worst-case regret-reduction greedy heuristic has no general optimality guarantee. XOR example below exhibits complementarity.
