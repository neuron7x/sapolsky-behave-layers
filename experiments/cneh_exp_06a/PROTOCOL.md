## A0 — model and causal API
Frozen 32-neuron feed-forward plant and R1 C/MPFR arithmetic, physical constants and instantaneous GABA route unchanged. The only cross-neuron edges are sources 24..31 -> receivers 0..15; no recurrent or receiver-to-source edges. At integer tick k, public observation O_k is constructed solely from the committed previous observation/interval: tick and previous 0.1 ms spike counts (receiver count and population count), previous action (WAIT/G0/G1 or initial None). This is an explicit limited engineering observation interface, not a claim that it is a measured biological sensor or the optimal policy input. No hidden topology, future inputs, voltage/w, latent RNG or conductance enters O_k. Do not execute untrusted Python policy code in the same process or claim a security sandbox. Only a fixed action enum can cross the action boundary; the runtime receives no callable or whole world.

advance accepts one validated immutable frame with exact tick, action and environment-only data: initial route mode index, strictly ordered interior route changes, per-neuron ordered unique external impulses in [k/10,(k+1)/10). It sees nothing beyond that interval. Action is constant on that interval. Sources are solved first only within the interval (valid for the frozen DAG); their actual spike events route at right-continuous mode and are delivered at exact time, receivers are integrated only to the committed boundary. Same-time impulses are grouped by count. Every external/route/current/received-synapse forcing boundary is an explicit adaptive solver stop. Each observation boundary is a hard numerical end and restart; accepted steps remain adaptive, not fixed 0.1 ms. A threshold event within 1e-9 ms of any such boundary is ambiguous and blocks the entire transaction, including near-coincidence at observation time. No rounding/event snapping. The state at k/10 is pre-impulse; source routing only uses actual events strictly inside the current interval. Threshold reset V=-58, w+=80 and exact rational root certification retained. Carry actual solver endpoint state (not a dense interpolation of it). No mutation of committed state until entire frame validates and solves. Failure leaves checkpoint and public observation unchanged.
