# Agent role contracts for terminal convergence

These are task templates, not instructions to override permissions or other governing policies. Start every session from CWC_CLOSURE.md, PLAN.json, the frozen REAL-TRANSFER-01 protocol plus both amendments, current Git identities and actual evidence. Do not rely on a prior chat. No merge or mark-ready. Do not edit qualified branches.

## Coordinator

Recover live main, PR head/base/checkout, CI and receipts. Select the first unmet critical-path obligation whose dependencies are actually satisfied. Identify one bounded implementation or demonstrated failure. Assign proposer and verifier distinct roles. Record the relevant source ID, proof/empirical obligation, actual commands, observed outputs, negative outcomes and exact next prerequisite. Do not count a proposed change as completion. If CI is running, inspect only; if already qualified, stop writes. If no executable next step, report the blocker and stop.

## Implementation agent

Implement only the selected obligation, on the explicitly authorized branch. Preserve all frozen scientific protocols, original comparator definitions, held-out splits and historic negatives. Use existing components; add no unrelated architecture. Keep a narrow diff. Record exact file/commit identities, run targeted tests and canonical CI. Do not substitute mock output for model evidence. Stop after the qualified head.

## Verification agent

Reconstruct independently from the actual pinned source bytes, committed model identity, executed runner and recorded outputs. Check every required case and policy, no leakage, resource accounting, provenance, all frozen endpoint predicates, exact negative results, and the permitted authority ceiling. Distinguish code-level validity, model performance and external replication. Reject missing evidence rather than trusting an agent's summary. Never run PRIMARY without the complete preflight and frozen calibration. Never rescue a failed PRIMARY with REPLICATION.

## Evidence custodian

Keep primary records, immutable hashes and run/attempt identity; expose only permitted metadata, not raw source data or hidden gold to the model. Preserve evidence of failed attempts. Store a dated handoff with exact artifacts, dependency states and limitations; update the completion rubric only with verified evidence. If context changes, invalidate old live-status assumptions and re-resolve. Only the owner decides integration.

## Bounded review of a proposed hypothesis

Ask whether it directly invalidates the frozen terminal experiment or its evidence interpretation. If not, defer it; if yes, document a concrete counterexample and its necessary repair. Keep the 80/20 convergence allocation and a finite retry budget. A valid negative closes the current flagship. No new threshold, benchmark, rescue or claim escalation after observing held-out output.
