## E01 — independent source-to-cohort binding

The existing source_intake.analyze reconstructs all three pinned source identities and frozen cohort hashes from actual bytes. The original preflight validates declared cohort hashes for internal consistency; it does not compare their membership with an actual reconstruction. A manifest can therefore be internally coherent while declaring a different cohort. The new additive gate must reconstruct the receipt from the pinned bytes on every admission; never trust a caller-supplied PASS receipt. Compare exactly the three source identities (family, canonical URL, immutable ref, SHA256, byte length, Git identity when present) and all six ordered cohort memberships, counts and cohort digests. Reject duplicate sources, alias/substituted paths, path traversal, symlinks, missing source bytes, wrong upstream identity, internally consistent but different cohort hashes, reordered membership and type-confused counts. Only consume the fixed cache filenames; source manifest paths must resolve to those same bytes inside the repository. An actual collision audit and linked-data terms review are separate obligations; do not invent either or mark them completed here. A source projection is not SOURCE_MANIFEST.json.

## E02 — model artifact byte binding

The original model-manifest validation checks digest syntax, decoding parameter canonical digest and runner/policy paths; it does not read the checkpoint, tokenizer, prompt template, calibration procedure or governor parameter bytes. Add strict artifact_bindings to a prospective model manifest: exactly the five original *_sha256 fields, each mapping to a repository-relative regular-file path and positive byte_length. A single-file representation is supported for each digest; an actual sharded checkpoint will require a disclosed canonical bundle representation before PRIMARY, not a digest placeholder. Bound total artifact bytes to 16 GiB and single artifacts to 8 GiB; stream SHA256. Reject malformed/duplicate file identities, unexpected fields, missing files, changed bytes, symlinks, non-regular files and invalid size. Verify runner and six comparator code identities and require these code files committed/clean using existing runtime binding; no claim they have scientifically valid behavior merely because bytes match. No model checkpoint, fake weights or invented manifest to be committed by this phase.
