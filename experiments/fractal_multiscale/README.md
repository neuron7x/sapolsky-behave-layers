# CWC Fractal Multiscale

Separate research module for testing the fractal hypothesis inside Cognitive Wiring Core.

This package does not claim biological equivalence or intelligence. It implements measurable
multiscale diagnostics:

- micro / meso / macro causal observations;
- fractal dimension, Hurst exponent and multiscale entropy;
- cross-scale coherence only through explicit semantic mappings;
- transition-boundary diagnostics;
- CWC adapter contracts for routing and instrumentation traces.

The core rule is fail-closed: no scale comparison is allowed when feature semantics are unknown.
