## A. Structural reachability certificate, not an actuator oracle
Native scalar GABA recurrence g[t+1]=a*(g[t]+0.5*n[t]), a=exp(-0.1/6), nonnegative integer arrivals n. Target [.4,.6] nS. For a trajectory inside the band, any nonzero arrival sends next g>=.9*a>.6. With no arrivals g decays, giving at most 25 consecutive in-band observations (24 intervals). Two separate in-band runs require at least 24 intervening out-of-band samples: if there is an arrival in the j transitions after the last in-band sample, g[t+j]>=.9*a^j>.6 for 1<=j<=24; if no arrivals, after exit it cannot re-enter by decay. Thus on N samples, occupancy count <= U(N)=25*floor(N/49)+min(25,N mod 49). This is a sound relaxed upper envelope for every initial state and every native arrival sequence, not a proof of attainability with current injection. Verify numerical margins, maximal-run/gap inequalities, U via independent exhaustive abstract run/gap dynamic program on small N, and check actual traces against the bound. Do not target impossible indefinite narrow-band invariance or equate B10 with regulation.

## D. Causal shadow predictor and objective (heuristics, not certified plant predictions)
Eight scalar deterministic shadow AdEx states (one/source), initialized V=-70 mV,w=0,spike=0, no synaptic current. Use the frozen native default parameters C=150 pF,gL=10 nS,EL=-70,VT=-55,DeltaT=2 mV,tauw=200 ms,a=2 nS,b=80 pA,Vreset=-58,Vpeak=30 mV. At t>0 update once with actual previous public action, Euler voltage/adaptation equations and capped exponential (arg<=20). At observation t, if bit is observed, override predicted spike with observed bit, apply reset/increment once iff spike, otherwise clip pre-reset voltage to [-100, nextafter(30,-inf)]; if erased use predicted spike and same reset/clip. At t=0 assimilate observed bits into initial spike flags only (all true initial spikes zero). This is a deterministic approximate predictor, not hidden state reconstruction; forecast future states without observed corrections, no future tape. At each block start forecast each of 8 group-waveform choices over 320 transitions, using current shadow spike bits for arrivals before stepping with the next stimulus; use exact recurrence for g. For each persistence-candidate reachable mode (exclude M3 only from control cost) and each endpoint of initial observed mean +/- .01 clipped at zero, compute MAE and band occupancy from forecasts. Control cost C = worst case over these forecasts of 0.5*(MAE/(MAE+.5) + 1 - occupancy_count/U(320)); C=0 if no reachable persistence-candidate. This is a minimax proxy over discrete model candidates and two initial endpoints, not a certified interval worst case or future-change robust guarantee. Check forecast trajectories obey the structural bound. No model-known truth in policy.
For information proxy, count transitions k for each of six ALL-mode pairs where shadow-predicted integer arrivals differ (use the same forecasted spike bits). I=mean over pairs of 1-(1-.75^8)^k, a full-bit-availability heuristic assuming independent erasure, not mutual information or a calibrated probability; ALL pairs used even if previously excluded to guard stale models. No future erasure schedule used. Optimize deterministic scalar score C + .25*(1-I) for DUAL, C for CONTROL_ONLY, 1-I for INFO_ONLY. Tie by group preference block parity, then waveform roster EARLY,LATE,MIDDLE,SPLIT, then group index. FIXED_ALTERNATE uses EARLY and group parity; exact emulator runs identical DUAL. All arms share estimator, shadow, observations, action menu and budgets; compute all forecast scores in all arms including baseline. Record forecast assumptions and scores, chosen action, shadow state and decision history. Forecast errors are descriptive and not evidence of sound physical reachability.
