# Акт · Взаємодоповнювані спостереження

[Протокол](./COMPLEMENTARY_PORTFOLIO.md) перед обчисленням зафіксовано в `f39752b`, реалізацію — в `c345e8c`.

Контрприклад до відбору одного типу зондів: зонд x дає гарантовану інформацію (2,0) проти двох альтернатив, зонд y — (0,2). Обидва окремо мають гарантований мінімум 0. Разом за бюджет два дають (2,2). Нуль однотипного максимуму не виправдовує висновку про відсутність спільного інформаційного каналу.

Нижня межа відповідає на питання, чи існує план, для якого проходження порога гарантоване. Верхня відповідає, чи всі плани виключені. Для кожного допустимого плану і кожної альтернативи межі адитивні за передумовою. Монотонність min та max дає L* ≤ I* ≤ U*. Звідси три зони: доведене проходження порога, доведене непроходження або недостатні межі. Відсутня верхня межа для хоча б одного допустимого використання забороняє загальне виключення.

Окремий продуктовий перебір на 5184 конфігураціях дає 1552 гарантовані проходження порога, 2784 виключення, 848 невизначених випадків. У **96** конфігураціях лише комбінація зондів долає поріг. Це підрахунок для замороженого скінченного простору, без популяційної інтерпретації. Тести порівнюють два оптимуми і відтворюють кожен вибраний портфель. [Тести](../../tests/test_decision_relevant_information_acquisition.py)
