# CNEH-EXP-04F — matched-budget response-aware causal reidentification

Prospective internal engineered neural pilot motivated by EXP04D/E (59,829/60,204 silent pair opportunities, 13/24 same-trajectory identification ceiling). Freeze before implementation and execution. Parent PR50 and PR51 must both be merged into main before experiment PR admission/execution. No parent edits, no tuning on new outcomes, no external replication or scientific promotion.

## Cohort and plant
Use exact EXP04D pinned BN-Syn simulator, four mode topology, 32 AdEx neurons, reference backend, dt .1 ms, receiver B drive 300 pA, gain 1, unchanged .5 nS route weight. No changes to neural parameters. Horizon 3200 transitions. Twelve new OOD seeds 88001..88012, four no-change seeds 88101..88104. Same four cyclic mode sequences and hidden switch windows as EXP04D, new independent Random(seed) switch draws. Same bounded noise, erasure and blackouts, separate Random(seed+1000000) sensor tape. All arms share identical initial state and exogenous tape per seed. No source voltage/adaptation, true conductance/spikes, seed, topology or hidden change schedule enters policy. Hidden changes are applied after observation and before transition. Truth only evaluator.

## Exact matched current budget, response-conditioned choice
Five arms: RESPONSE_ROLLING, EXACT_EMULATOR (same implementation as RESPONSE_ROLLING), ALTERNATE_ROLLING, RESPONSE_RESET, ALTERNATE_RESET. All have the exact same 160-on/160-off packet schedule, 10 packets per episode, 1600 stimulated ticks, one group of four sources at 500 pA per stimulated tick, zero otherwise; source current L1 3,200,000 pA*ticks per episode, exact equality in every pair and at every prefix. Receiver drive identical. Physical energy NOT_VALIDATED. Packet group fixed throughout each on interval, chosen causally at start. This is a fixed resource intervention experiment, not unconstrained optimal tracking; forced stimulation can be unfavorable, and disconnected modes still receive diagnostic pulses. Packet actions are classified without claiming useful control in disconnected/ambiguous states.

Every even-numbered packet (0-based) is a verification packet; odd packets also verify unless a conditional singleton connected mode and observed mean B GABA below .5 nS permit a tracking packet. Tracking chooses first predicted connected group; the other packet rules are identical across schedulers except choice of verification group. A tracking packet is marked TRACK at a tick only while the conditional singleton still predicts its group connected and observed mean below target; otherwise mark PACKET_CONTINUATION. A verification packet is marked PROBE throughout; rest is REST. No tracking under ambiguity or predicted disconnection. Count actual disconnected stimulation and tracking separately.

ALTERNATE selects verification groups by alternating a public verification counter starting at group 0. RESPONSE selects among groups using a causal, smoothed response rate (1+observed one bits during previous stimulation)/(2+number of non-erased bits during previous stimulation), per group, using only observations at t of source spiking after action t-1. Count all such bits, including zeros; missing bits contribute neither numerator nor denominator. For verification, structural discrimination weight is the number of candidate-mode pairs differing on a group. If no ambiguity, use ALL modes for verification. Score = weight * response_rate, evaluated with exact rational comparison. Among positive weights, if a group has not been stimulated in the previous two packets, prioritize it (ties by older last packet then group index). Otherwise maximize score, ties by older last packet then group index. When only one group has positive discrimination, select it. Log observed responses, score inputs, candidate sets, selected group and reason. This is an explicitly heuristic expected discrimination proxy, not calibrated mutual information or demonstrated fatigue mitigation. Report silence and actual responses; no favorable result assumed.

## Evidence retention with bounded age
Use exact EXP04C instantaneous support. Prior nominal candidate M0 at t=0, conditional only. RESET uses exact EXP04D epoch intersection/contradiction and every-400-observation reset. ROLLING maintains last exclusion tick per mode, initial exclusions for nonnominal modes timestamp 0. At observation t, expire each exclusion iff age >=400; then intersect remaining support with current instantaneous support. If empty, record contradiction, invalidate old exclusions, and restart from current instantaneous support. Otherwise update last exclusion time for every mode excluded by current instantaneous support, preserving unexpired exclusions across absolute tick 400 boundaries. A renewal is per-evidence expiry, not unconditional reset; record expiry and contradiction separately, along with the full last-exclusion vector and instantaneous support every tick. Retained evidence is conditional on mode persistence; never call a singleton a guaranteed current truth. No forced singleton or future-informed reset. Contradictions on no-change fixtures fail closed. Sound instantaneous support must contain true transition mode always. No hidden switch can be guaranteed detectable absent informative evidence.
