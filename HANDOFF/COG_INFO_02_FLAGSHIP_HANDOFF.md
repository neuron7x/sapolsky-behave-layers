## Candidate flagship principle

Preserve causal ambiguity explicitly. If all surviving worlds induce the same immediate
decision, do not spend compute identifying which world is true. If worlds disagree,
acquire only evidence with certified information against action-flipping alternatives.
If those alternatives have zero certified information under every admissible channel,
abstain rather than hallucinating resolution.

This is a synthesis candidate, not a novelty claim.
