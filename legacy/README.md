# legacy/

Preserved, superseded predecessors of the CWC system. Kept for provenance;
NOT part of the active codebase and NOT covered by `make -f Makefile.cwc verify`.

## `cognitive-weave-kernel-archive.zip`
The earlier conceptual scaffold of Cognitive Weave Kernel (48 Python files,
37 docs, versions v0.1.0 → v0.4.0). It framed the CWC vision (router / memory /
plasticity / topology / semiotics / DCSA) BEFORE the falsification-first
empirical work in this repository. Superseded by the evidence-backed
experiments under `experiments/` and `artifacts/`. Its vision documents
(CHARTER, ARCHITECTURE, ROADMAP, VALIDATION_REPORT) are copied into
`docs/vision/` for reference. Full source is preserved here as a single
archive rather than a live tree, to keep the canonical system clean.

Backup of everything (git bundle + tarballs) also lives outside the repo at
`~/CWC_CONSOLIDATION_BACKUP_2026-07-16/`.
