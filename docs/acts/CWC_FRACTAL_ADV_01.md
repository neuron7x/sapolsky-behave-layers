# CWC-FRACTAL-ADV-01 — Adversarial Multiscale / Execution-Reality Programme

**Status:** FROZEN BEFORE FRESH TRACE EXECUTION
**Scope:** diagnostic sidecar + archived CWK runtime
**Scientific ascension authority:** none
**VIA authority:** none; VIA descendants remain controlled by `scripts/via_gate.py`

## 1. Intent

Attack the strongest failure modes in the repository's legacy "fractal/multiscale" and conditional-compute
ideas before allowing either to contribute to architecture claims.

This act deliberately separates four propositions that are often conflated:

1. a trace has statistics at several labelled levels;
2. two level-labelled trajectories are associated;
3. the association survives shared exogenous drivers and time-preserving nulls;
4. a hierarchical mechanism causally creates useful computation or physically skips work.

Only (3) can support the narrow phrase **residual multiscale organization in the measured trace**.
It cannot support "fractal cognition", intelligence, biological equivalence, or causal hierarchy.
Only an intervention can address (4).

## 2. Adversarial cells

The execution is partitioned into independent failure-seeking cells:

- **E1 — Semantic-scale audit:** reject level labels that do not have explicit composition semantics.
- **E2 — Trajectory statistics:** replace last-sample vector cosine similarity with time-aligned rank
  association over prespecified feature mappings.
- **E3 — Common-driver attack:** remove exact repeated-shape effects (`batch_size`, `sequence_length`)
  before evaluating residual association.
- **E4 — Null attack:** require separation from within-stratum shuffle, circular-shift and block-permutation
  null families with a max-null family-wise test.
- **E5 — Estimator calibration:** demonstrate how short-series Hurst/box/entropy diagnostics behave under
  iid, AR(1), random-walk and trend controls. These estimators are diagnostic-only unless independently
  calibrated; they are not acceptance statistics in this act.
- **E6 — Execution-reality audit:** dynamically intervene on archived CWK controller budgets/modes and
  count actual expert inputs. A gate value that changes while expert work is invariant is semantic
  masking, not conditional execution.
- **E7 — Reproducibility / evidence:** fresh trace generation must use the repository's archived CWK,
  frozen seeds/protocol, checksummed outputs, machine verdicts and regression gates.

## 3. Known v1 weaknesses being tested, not assumed

The v1 fractal sidecar currently computes cross-scale coherence from only the latest observation for each
scale, despite accepting a time series. Its implementation declares multiple null models in YAML but
executes one time-shuffle family. It can also map constant features and silently convert degeneracy to a
zero cosine value. These are testable implementation facts; this act must either repair or explicitly
quarantine them.

The archived CWK attention module documents that its sparse topology is implemented with a dense
`nn.MultiheadAttention` mask. The controller applies active/depth gates after `ExpertEcology` produces
its update. This act must verify dynamically whether those semantics correspond to physical work
reduction; source inspection alone is not accepted as the final execution verdict.

## 4. Fresh-trace protocol

Fresh data are generated only after code + protocol freeze. Three model seeds are prespecified:

```
101, 211, 307
```

For each seed:

- `fixed_shape`: 64 runs, batch/sequence shape fixed;
- `variable_shape`: 72 runs, deterministic repeated 12-shape cycle.

The archived `cognitive-weave-kernel-archive.zip` is the only CWK source. No external desktop path is
allowed. Traces must record runtime config and richer internal telemetry needed to distinguish
endogenous routing variation from shape-driven compute variation.

## 5. Confirmatory multiscale estimand

For each prespecified semantic pair `(x_t, y_t)`:

1. align by timestamp;
2. reject a pair if either trajectory is effectively constant;
3. compute raw Spearman association;
4. where repeated shape strata exist, subtract the within-`(batch_size, sequence_length)` mean from
   each trajectory and compute residual Spearman association;
5. aggregate as the mean absolute residual Spearman coefficient over valid pairs.

A pair whose residual variance collapses after shape removal is classified `COMMON_DRIVER_EXPLAINED`,
not evidence for organization.

## 6. Null families and multiplicity

Three prespecified residual nulls are required:

- `within_stratum_shuffle_target` — destroys within-shape source/target pairing while retaining shape;
- `circular_shift_target` — preserves each target trajectory's marginal/autocorrelation structure;
- `block_permutation_target` — preserves local target blocks while destroying global alignment.

The primary p-value is computed against the iteration-wise **maximum** null statistic across families.
This is a conservative family-wise test. Individual-family p-values are diagnostics only.

## 7. Acceptance gate

A trace can receive `RESIDUAL_MULTISCALE_ORGANIZATION_SUPPORTED` only if all are true:

- all three scales are present;
- series length >= 64 per scale;
- at least 75% of prespecified pairs remain non-degenerate after confounder handling;
- every required edge (`micro→meso`, `meso→macro`) retains at least one valid pair;
- observed residual coherence exceeds the max-null mean by at least 0.10;
- family-wise empirical p <= 0.05;
- synthetic endogenous positive control passes;
- synthetic independent and common-driver-only controls do not pass.

If pair coverage collapses after exact shape residualization, the verdict is
`MULTISCALE_ORGANIZATION_NOT_IDENTIFIABLE_UNDER_CURRENT_INSTRUMENTATION`, not a negative biological or
architectural claim.

## 8. Execution-reality gate

For identical model weights and tokens, intervene on controller `max_active_tokens`, `max_depth`,
controller mode, `max_active_experts` and attention budget where legal.

The audit counts rows actually received by each routed expert using forward hooks and records shared
expert rows, routed expert rows and output rows. If a controller gate changes but expert-input counts
are invariant, that control is classified `SEMANTIC_GATE_ONLY` for the archived CWK implementation.

No latency threshold is used to establish physical skipping. Wall-clock timing is diagnostic because
this execution environment is CPU-only and not production hardware.

## 9. Claim boundary

This act may establish only implementation/evidence boundaries:

- whether the current trace instrument can identify residual multiscale dependence;
- whether the v1 multiscale statistic/null design is adequate;
- whether archived CWK control gates physically skip the work they purport to govern.

It cannot establish intelligence, cognition, neural equivalence, general adaptive-compute value, GPU
speedup, or any VIA-V2+ claim.
