# External Review and Independence Protocol

## Minimum independence conditions
The replicator: did not build the mechanism under test; does not change the primary
hypothesis after seeing results; works from a **frozen release**; receives the protocol
before running; records the environment; keeps raw outputs; publishes a deviation log;
writes a separate reproduction report.

## Blind analysis (recommended)
System labels hidden · run identifiers randomized · analysis performed before
unblinding · label mapping revealed only after the verdict is locked.

## Acceptance
independent operator · frozen release · fresh environment · primary result reproduced ·
deviations disclosed · raw artifacts available · separate signed report.

**A re-run by the original author is NOT independent replication.** CWC-L8 stays
`NOT_TESTED` until this protocol is executed by a third party.
