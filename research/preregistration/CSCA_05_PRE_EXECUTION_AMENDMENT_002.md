# CSCA-05 PRE-EXECUTION AMENDMENT 002 — Context-stratified qualification

**Frozen before authoritative calibration.**

Because PROSE and CODE are declared contexts rather than nuisance labels, a pooled pass could hide failure in one context. Therefore every coverage and accepted-case accuracy condition in the CSCA-05 qualification rule must pass:

1. on the pooled cohort;
2. on PROSE alone;
3. on CODE alone.

Selective false causal authority must be exactly zero in every stratum. Shadow noninterference and model-state immutability are required on every evaluated prompt, not only in aggregate.

This amendment does not change metrics, candidates, seeds, data splits, delta rule, budget grid, or outcome definition.
